# 老天祿新版電商系統原型

這是一個以前台公開頁面為需求藍本重做的現代化電商網站原型，不使用舊站程式碼。

## 線上 Demo

👉 **[https://gbi0426-terry.github.io/lautianlu-modern/](https://gbi0426-terry.github.io/lautianlu-modern/)**

## 已完成的示範功能

- 品牌首頁與品牌故事頁
- 商品分類、搜尋、口味與數量選擇
- 購物車與結帳流程
- 產生示範訂單與訂單查詢
- 手機會員登入/註冊示範
- 團體訂購需求表單
- 營運後台：商品管理、訂單搜尋/篩選、訂單狀態更新、訂單明細、CSV 匯出、團購需求、營收摘要
- 後台圖片管理：首頁主視覺、品牌故事圖、門市圖、商品圖可貼網址或選本機圖片替換
- localStorage 暫存資料，可在重新整理後保留示範資料

## 建議正式版後續串接

- 後端 API 與資料庫
- 綠界或藍新金流
- 電子發票
- 簡訊驗證
- LINE 官方帳號通知
- 物流與運費規則
- 後台權限管理

## 本機預覽

```bash
python3 -m http.server 5177
```

再開啟：

```text
http://localhost:5177
```
